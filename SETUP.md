# Coastline Crane - Repository Setup

## Project Overview

**Repository**: `coastline-crane`  
**Owner**: Unicorn0-0Cakes  
**Visibility**: Public  
**Live Site**: https://unicorn0-0cakes.github.io/coastline-crane

This repository hosts the Phase 1 website for Coastline Crane Repair — a professional industrial crane repair and parts service provider.

## Website Purpose

> Establish immediate trust, capture inbound parts and repair inquiries, and support growth without adding operational friction.

## Phase 1 Deliverables

✅ **Homepage (index.html)**
- Hero section: Professional headline + CTA phone button
- Proof of Trust: 30+ years, A+ BBB rating, parish work credentials
- Differentiation: Key selling points ("When others can't help", "If we can't fix it, you don't pay", etc.)
- Parts & Repairs inquiry form (simple, low-friction)
- Human-focused footer with contact info

✅ **Styling (style.css)**
- Professional, clean aesthetic
- Responsive design (mobile-first approach)
- Modern color scheme (deep purple gradient)
- Forms and CTA buttons optimized for conversion

✅ **GitHub Pages Enabled**
- Branch: `main` → Published
- Build source: Root folder (`/`)
- HTTPS: Enforced

## How to Update Content

### Edit the Homepage
1. Click on `index.html` in the GitHub interface
2. Click the pencil icon (Edit) to make changes
3. Commit changes to `main` branch
4. Site updates within ~1-2 minutes

### Update Styling
1. Click on `style.css`
2. Make CSS changes and commit
3. Changes live on next deploy

## Current Technology Stack

- **Hosting**: GitHub Pages (free, always on)
- **Frontend**: HTML5 + CSS3 (no build dependencies)
- **Version Control**: Git/GitHub
- **Domain**: Available for custom domain configuration

## Key Design Principles

1. **Clarity over beauty**: User understands what Coastline does in 10 seconds
2. **Trust over cleverness**: Professional, straightforward messaging
3. **Human over automated**: Phone-first culture, real people
4. **No friction**: Forms are short, contact is easy
